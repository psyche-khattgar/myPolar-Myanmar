# myPolar: Myanmar Language Polarization Analysis

## Overview

This project is part of the AI Engineering course taught by Dr. Ye Kyaw Thu. It focuses on developing and extending the myPolar dataset for Myanmar-language polarization analysis.

Building on the POLAR data extension work from Assignment 2, the project explores three key Natural Language Processing (NLP) tasks:

- **Polarization Detection**
- **Polarization Type Classification**
- **Polarization Manifestation Identification**

The goal is to contribute to Myanmar-language NLP research through dataset development and machine learning experiments.

## Project Development

- **Assignment 2:** POLAR Data Extension for the Myanmar Language
- **Assignment 7:** Polarization Detection, Polarization Type Classification, and Polarization Manifestation Identification on Developing myPolar Data
